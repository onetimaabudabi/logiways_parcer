🔍 ДИАГНОСТИКА ПРОБЛЕМ:

Если компания не загружается:
1. Запустите check_companies.py
2. Скопируйте правильное название из companies_reference.json
3. Обновите companies.json
4. Запустите скрипт снова

Если не загружаются локации:
1. Проверьте что в Excel указаны правильные страны (ISO2 коды: RU, CN, VN и т.д.)
2. Проверьте что API ключ Yandex действителен
3. Смотрите логи с префиксом "LOC [FIND]" или "LOC [CREATE]"

Если не загружаются тарифы:
1. Проверьте что сегменты успешно загружены (есть ли их ID в логах)
2. Проверьте что в Excel заполнены поля: cost, currency, container_type
3. Смотрите логи с префиксом "Тарифов создано:"
