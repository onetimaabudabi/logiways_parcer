# Logiways Parser — парсер тарифов транспортных компаний

Проект собирает тарифы морских и железнодорожных перевозок из файлов
транспортных компаний (ТК) разных форматов (PDF / XLSX / DOCX / TXT),
приводит их к единой структуре и загружает в систему **Logiways** через API.

> Новому разработчику: начните с раздела [«Быстрый старт»](#быстрый-старт)
> и файла [CLAUDE.md](CLAUDE.md). Работа ведётся вместе с Claude Code —
> для добавления новой ТК есть готовый скилл, см. ниже.

---

## Что делает проект

Каждая транспортная компания присылает свой файл с тарифами в собственном
формате. Единого стандарта нет, поэтому под **каждую ТК пишется отдельный
парсер** в папке `parsers/`. Все парсеры приводят данные к единой структуре
`TariffSegment` (см. `parsers/models.py`), после чего результат:

1. выгружается в общий Excel `tariff_analysis_TEST.xlsx` (для проверки глазами);
2. загружается в API Logiways скриптом `send_api_New.py` (с геокодированием
   пунктов маршрута через Yandex).

---

## Конвейер обработки (pipeline)

```
Файлы тарифов ТК (скачиваем вручную и кладём в папку data/)
        │
        ▼
main.py                     ── вызывает нужные парсеры из parsers/
   └─ parsers/<company>.py  ── каждый парсит свой формат → TariffSegment
        │
        ▼
tariff_analysis_TEST.xlsx   ── общий результат (лист «Raw Data»)
        │
        ▼
send_api_New.py             ── читает xlsx, геокодирует, грузит в Logiways API
   └─ geocode_locations_yandex_toponyms.py  ── координаты пунктов (Yandex)
```

> **Google Drive:** автоскачивание (`drive/service.py`) сейчас **не работает и не
> используется**. Файлы тарифов скачиваем вручную и кладём в папку `data/`,
> затем прописываем путь к ним в `main.py` (`parse_all()`).

Опорные модули, которыми пользуются все парсеры:

- **`shared.py`** — справочники (`port_dict`, `region_dict`, `country_dict`,
  `container_size_dict`, `stations_dist`, `port_city_dict`) и функции
  нормализации (`get_country()`, `get_city_port()`, `get_city_station()`).
  Импортируется ~40 парсерами.
- **`get_tables_sites.py`** — извлечение таблиц и текста из PDF (`pdfplumber`).
  Импортируется ~26 парсерами.
- **`parsers/models.py`** — датакласс `TariffSegment` (единая структура записи).
- **`parsers/utils.py`** — `to_segments()`, `segments_to_df()` (сборка результата).

## Быстрый старт

```bash
# 1. Зависимости
pip install pandas pdfplumber openpyxl python-docx requests pycountry Babel

# 2. Положить файлы тарифов в data/ и прописать пути в main.py (parse_all)

# 3. Прогнать парсеры → tariff_analysis_TEST.xlsx
python main.py

# 4. Задать ключи/доступы (см. раздел «Настройка ключей и доступов»)
#    и загрузить результат в Logiways API
python send_api_New.py
```

Какие ТК парсятся при запуске `main.py` — задаётся вручную в функции
`parse_all()` (файл `main.py`): нужные строки `segments += ...parse(...)`
раскомментируются, лишние остаются закомментированными. Это рабочий,
«ручной» способ управления — не пугайтесь большого закомментированного блока.

## Настройка ключей и доступов

Всё необходимое сосредоточено в `send_api_New.py` (загрузка в API + геокодирование).

### 1. Yandex Geocoder API (координаты пунктов маршрута)

Нужен для загрузки в API — по названиям городов/портов проставляются координаты.

- **Где взять ключ:** [Yandex Cloud → Geocoder API (JavaScript API и HTTP Геокодер)](https://developer.tech.yandex.ru/services/).
  Зарегистрировать приложение, включить «HTTP Геокодер», скопировать ключ вида
  `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`.
- **Как задать** (перед запуском, PowerShell):

  ```powershell
  $env:YANDEX_API_KEY = "ваш-ключ"
  ```

  Код читает ключ из переменной окружения `YANDEX_API_KEY` (или `GEOCODER_API_KEY`).
  В `send_api_New.py` есть «запасной» захардкоженный ключ — его стоит заменить
  своим или полагаться на переменную окружения.

### 2. Доступ к API Logiways (авторизация по SMS)

В блоке `if __name__ == "__main__":` в `send_api_New.py`:

- **`base_url`** — адрес стенда. Боевой `https://logiways.ru`, тестовый
  `https://test.logiways.ru`. Меняется в строке создания `LogiwaysClient(base_url=...)`.
- **Авторизация** идёт по телефону + коду из SMS:
  `request_sms(phone)` → `verify_sms(phone_number, code)`.
- Сейчас в коде прописаны **тестовый номер** (`test_phone`) и **тестовый код**
  (`sms_code = "777777"`), работающие на тестовом стенде (`request-sms` шлёт
  `"test": True`). Для боевого стенда подставьте реальный номер и вводите
  реальный код из SMS.

### 3. `companies.json` — реквизиты транспортных компаний

Список ТК (название, контактное лицо, телефон, email, языки). При загрузке
скрипт по нему находит/создаёт организации в системе. Пополняется вручную при
добавлении новой ТК.

### 4. Google Drive — **не используется**

`drive/service.py` и `drive/credentials.json` (сервисный аккаунт Google)
оставлены в репозитории, но автоскачивание сейчас не работает и не требуется.
Файлы тарифов кладём в `data/` вручную.

### Как добавить новую транспортную компанию

Используйте скилл **`create-tariff-parser`** (лежит в
`.claude/skills/create-tariff-parser/`). Дайте Claude файл тарифов и попросите
«создай парсер» — скилл сам изучит эталонный `parsers/panda.py`, справочники
`shared.py`, создаст `parsers/<name>.py` и подключит его в `main.py`.

## Структура файлов

### Основной конвейер (не трогать)

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа парсинга. Собирает сегменты из `parsers/` → `tariff_analysis_TEST.xlsx` |
| `send_api_New.py` | Загрузка тарифов в API Logiways (читает `tariff_analysis_TEST.xlsx`) |
| `geocode_locations_yandex_toponyms.py` | Геокодирование пунктов через Yandex (используется в `send_api_New.py`) |
| `shared.py` | Справочники портов/станций/стран и функции нормализации |
| `get_tables_sites.py` | Извлечение таблиц/текста из PDF |
| `parsers/` | Парсеры отдельных ТК + `models.py`, `utils.py` (**не удалять**) |
| `drive/service.py` | Скачивание файлов ТК с Google Drive — **не используется** |

### Данные и артефакты

| Путь | Назначение |
|------|-----------|
| `data/` | Исходные файлы тарифов ТК (PDF/XLSX/DOCX) — **кладём сюда вручную** |
| `drive/credentials.json` | Ключ сервисного аккаунта Google (⚠️ секрет; Drive сейчас не используется) |
| `tariff_analysis_TEST.xlsx` | Результат парсинга (вход для загрузки в API) |
| `Транспортные компании.xlsx` | Историческая «сводная» таблица ТК |
| `openapi.json` | Спецификация API Logiways (справочник по эндпоинтам) |
| `tablets/`, `output/`, `companies_json/` | Промежуточные выгрузки/отладка |

### Вспомогательные скрипты (вне основного конвейера)

| Файл | Назначение |
|------|-----------|
| `generate_tz.py`, `generate_tz2.py` | Генераторы ТЗ (docx) из шаблона договора — разовый инструмент |
| `parse_companies.py` | Разбор `Транспортные компании.xlsx` по листам в `output1/` — отдельный сценарий |

## Известные проблемы / что можно доделать

- **`send_api_New.py`, `exit(0)` в теле `__main__`** — исторически прерывал
  скрипт до загрузки тарифов (около 1615+ записей не попадали в API).
  При запуске загрузки убедитесь, что выполнение доходит до этапов
  «Загрузка отправлений / тарифов», а не обрывается ранним `exit(0)`.
- **stopovers** — отключены (endpoint возвращает 422, см. комментарий в конце
  `send_api_New.py`).
- В `main.py` активная конфигурация парсеров задаётся руками
  (комментирование/раскомментирование строк) — при передаче стоит договориться
  о более явном способе выбора ТК.
