# CLAUDE.md — гид для разработчика (и для Claude Code)

Этот файл читается Claude Code автоматически. Он же — краткая шпаргалка для
нового разработчика, который принимает проект.

## О проекте в двух предложениях

Проект парсит тарифы транспортных компаний (ТК) из файлов разного формата
(PDF/XLSX/DOCX) в единую структуру `TariffSegment` и загружает их в API Logiways.
Под каждую ТК — свой парсер в `parsers/`. Файлы тарифов скачиваем вручную и
кладём в `data/` (автоскачивание с Google Drive не используется).
Подробности — в [README.md](README.md).

## Главное правило

**Новая транспортная компания = новый парсер.** Для этого есть скилл
`create-tariff-parser` (`.claude/skills/create-tariff-parser/SKILL.md`).
Когда пользователь присылает файл тарифов и просит «создай парсер / распарси
файл / добавь компанию» — используй этот скилл. Не пиши парсер «с нуля» вручную,
если скилл применим: он знает эталон, справочники и порядок интеграции.

## Карта кода

- `main.py` — точка входа парсинга → `tariff_analysis_TEST.xlsx`.
  Активные ТК выбираются в `parse_all()` комментированием строк `segments += ...`.
- `send_api_New.py` — читает `tariff_analysis_TEST.xlsx` и грузит в API Logiways.
- `shared.py` — справочники (порты, станции, страны, контейнеры) и функции
  нормализации. **Первое место, куда смотреть**, если пункт маршрута не
  распознаётся: возможно, его нет в `port_dict` / `stations_dist`.
- `get_tables_sites.py` — извлечение таблиц/текста из PDF.
- `parsers/models.py` — структура `TariffSegment` (все поля с типами).
- `parsers/utils.py` — `to_segments()`, `segments_to_df()`.
- `parsers/panda.py` — **эталонный парсер**, бери за образец.

## Рабочий процесс

```bash
# файлы тарифов кладём в data/ вручную, пути прописываем в main.py (parse_all)
python main.py            # парсинг → tariff_analysis_TEST.xlsx
python send_api_New.py    # загрузка в API (нужны ключи, см. README)
```

Проверять результат парсинга нужно глазами в `tariff_analysis_TEST.xlsx`
(лист «Raw Data») до загрузки в API.

## Ключи и доступы (кратко; подробно — в README)

- **Yandex Geocoder** — ключ в переменной окружения `YANDEX_API_KEY`
  (`$env:YANDEX_API_KEY = "..."`). Нужен для `send_api_New.py`.
- **API Logiways** — `base_url` + авторизация по SMS (`request_sms`/`verify_sms`)
  в блоке `__main__` файла `send_api_New.py`. Есть тестовые номер и код для
  тестового стенда.
- **Google Drive автоскачивание не работает и не нужно** — файлы тарифов
  скачиваем вручную в `data/`.

## Соглашения

- Комментарии и переписка — на русском.
- Не удаляй ничего в `parsers/` — там лежат все рабочие парсеры, в т.ч. старые.
- Секреты (`drive/credentials.json`, API-токены) не коммитить.
- При правке справочников в `shared.py` помни: их импортируют ~40 парсеров,
  меняй ключи аккуратно.

## Известные подводные камни

- В `send_api_New.py` в блоке `__main__` встречается ранний `exit(0)` —
  проверь, что загрузка реально доходит до этапов «отправления/тарифы».
- `stopovers` в загрузке отключены (endpoint 422).
