# Парсер ТрансКонтейнера для PDF файлов

## Описание
Добавлена функция `parse_TransContainer_PDF()` для парсинга тарифов из PDF документов ТрансКонтейнера.

## Структура данных
Парсер извлекает тарифы на перевозки контейнеров из Китая, Кореи и Вьетнама в Россию через порт Восточный.

### Схема маршрутов:
1. **SEA (морской фрахт)**
   - Начало: Порт отправления (китайский, корейский или вьетнамский)
   - Конец: Восточный (порт)

2. **RAIL (железная дорога)**
   - Начало: Восточный (порт)
   - Конец: Станция назначения (российская ж/д станция)

## Типы контейнеров
- `20GP`: 20-футовый контейнер с лимитом веса 24 тонны
- `40HC`: 40-футовый контейнер с лимитом веса 30 тонн

## Родительские локации
Для каждого сегмента устанавливаются родительские локации (города):
- **SEA**: parent_start = город порта отправления, parent_end = Владивосток
- **RAIL**: parent_start = Владивосток, parent_end = город станции назначения

## Функции парсера

### `parse_TransContainer_PDF(file_path: str) -> list[TariffSegment]`
Основная функция для парсинга PDF файла.

### `_normalize_station_name(station_name: str) -> str`
Вспомогательная функция для нормализации названий станций (корректирует регистр букв).

## Использование
```python
from parsers.transcontainer import parse

# Парсинг PDF файла
segments = parse("data/0916.pdf")

# Парсинг Excel файла (существующая функциональность)
segments = parse("data/transcontainer.xlsx")
```

Парсер автоматически выбирает нужный парсер в зависимости от расширения файла.

- Компания: ТрансКонтейнер
